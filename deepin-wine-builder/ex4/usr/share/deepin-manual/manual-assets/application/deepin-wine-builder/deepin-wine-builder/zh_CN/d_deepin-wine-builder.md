# 统信Windows应用兼容引擎|deepin-wine-builder|

## 概述

统信Windows应用兼容引擎（以下简称“兼容引擎”）是一款使用 Deepin Wine 运行/打包 Windows 应用的工具。支持运行本地 exe，支持将本地 exe 安装程序转换成 deb 安装包。

## 使用入门

首次运行兼容引擎（包括安装兼容引擎后直接安装运行Windows安装程序），请先同意《统信Windows应用兼容引擎软件许可及服务协议》。

![Img](./fig/img-20250520155937.jpg)

### 运行兼容引擎

1. 单击任务栏上的启动器图标 ![deepin_launcher](../common/deepin-launcher.svg)（在deepin 20上图标为 ![deepin20_launcher](../common/deepin_launcher.svg)） ，进入启动器界面。
2. 上下滚动鼠标滚轮浏览或通过搜索，找到兼容引擎图标![Img](../common/deepin-wine-builder.svg)，左键单击运行。
3. 右键单击![Img](../common/deepin-wine-builder.svg)，您可以：
   - 选择 **发送到桌面**，为应用程序在桌面创建快捷方式。
   - 选择 **发送到任务栏**，将应用程序固定到任务栏，方便快速启动。
   - 选择 **开机自动启动**，将应用程序添加到开机启动项，在电脑开机时自动运行该应用程序。

![Img](./fig/img-20250212102439.png)

### 关闭兼容引擎

- 在兼容引擎界面单击 ![Img](../common/close.svg) 退出兼容引擎。
- 右键单击任务栏上的![Img](../common/deepin-wine-builder.svg)，选择 **关闭所有** 来退出兼容引擎。
- 在兼容引擎界面单击![Img](../common/icon_menu.svg)，选择 **退出** 来退出兼容引擎。

## 操作介绍

### 账号登录

兼容引擎支持 deepin ID 一键登录：
- 当系统已经登录 deepin ID 账号时，打开兼容引擎即为登录状态。
- 当系统退出 deepin ID 账号时，兼容引擎也会变为未登录状态。
- 当系统未登录 deepin ID 账号时，打开兼容引擎，点击“登录”入口会拉起系统账号登录模块，扫码或其他方式登录后，兼容引擎和系统均处于登录状态。
- 在兼容引擎内退出账号时，系统账号登录状态也会变为未登录。

![Img](./fig/img-17875491257806.png)

个人中心主要功能：
- 我的投递：当前账号下投递过的应用
- 我的心愿：当前账号下提交过的心愿单
- 我的反馈：当前账号下提交过的问题反馈
- 退出：退出当前账号

### 运行应用

#### 双击运行

系统上已安装兼容引擎，您可以直接双击下载在本地的exe来运行应用，双击之后，程序自动启动wine。

![Img](./fig/img-20250212103739.png)

若运行成功，则直接打开应用。
若运行失败，您可以通过“修复”或“我要调试”（详见下文“应用调试”章节）进行调试，提升运行成功率。

点击“常见问题”可以打开帮助手册-常见问题，为调试提供参考建议。

## 常见问题

### 绿色软件注意事项

#### 如何运行绿色软件

绿色软件是直接运行无需安装的，绿色软件运行后会在兼容引擎首页“我的应用”内生成快捷方式，后续可以直接运行。
如果运行的绿色应用没有完全退出，可以检查应用是否最小化在系统右下角的托盘内。
对于应用无法退出的情况，打开任务管理器，搜索 exe的名称找到对应的进程，然后选中，在右键菜单里面点击“强制退出”：

![Img](./fig/img-20250212173026.png)

####  如何打包绿色软件

如果要打包的应用是一个绿色软件，会弹出这样子的提示：

![Img](./fig/img-20250212174536.png)

至于什么时候该选“打包应用本身”，什么情况选“打包文件夹”，取决于运行的应用本身。
如果运行的绿色软件是一个非常简单的应用，同级目录下没有任何文件就能够跑起来，比如这样：

![Img](./fig/img-20250212174559.png)

那么在打包的时候可以直接选择“打包应用本身”，此时 deb 包里就仅包含这个 exe 文件。

但大多数情况下，大多数绿色软件除了运行的 exe 以外，还会自带运行的 dll、资源文件、各种配置文件，比如这样：

![Img](./fig/img-20250212174623.png)

那么打包的时候就需要选择“打包文件夹”，然后选择整个绿色软件解压后的路径。兼容引擎只是默认打开 exe 所在的目录，如果 exe 所在的层级目录很深，你需要选择更上层的文件夹才能保证将绿色软件完全打包。

### 应用首次安装可以运行，退出后再次运行失败

在兼容引擎V3.2以后的版本上出现这种情况，可以进入应用的高级调试页面，直接点击“调式运行”，如前文提到的：

![Img](./fig/img-20250310171737.png)

此时就可以看到应用运行日志了，我们在日志窗口里可以看到这样的错误：

>0114:err:module:import_dll Library MSVBVM60.DLL (which is needed by L"C:\\Program Files (x86)\\Kingsoft\\TypeEasy\\TypeGame\\Mole\\TypeGame.exe") not found
0114:err:module:loader_init Importing dlls for L"C:\\Program Files (x86)\\Kingsoft\\TypeEasy\\TypeGame\\Mole\\TypeGame.exe" failed, status c0000135

从日志中可以明显看到因为应用缺失了 dll，而这些 dll 在当前版本的 wine 还没有实现。目前兼容引擎 V3.2 在调试日志窗口内针对错误日志提供了修复建议，点击文字链后即可跳转到组件安装模块安装对应的dll组件：

![Img](./fig/img-20250310172446.png)

应用可能缺多个 dll，在补完一个 dll 之后再次点击调试运行，又报一样的错误，只不过 dll 的名字不一样，一些小的应用可以在“组件安装”补完 dll 之后运行。

![Img](./fig/img-20250310172706.png)

如果无法在组件列表中安装缺失的 dll，那就只能自己从网上下载 dll 后，在高级调试界面的“调试工具”里打开容器 C 盘，将 dll 手动复制到 windows/system32 （或 windows/syswow64）下。

### 应用窗口黑屏

Wine提供了三种渲染方式：
- gdi：禁用 3D 加速；
- opengl ：默认情况下 wine 将使用 OpenGL 实现 Direct3D 渲染 API；
- vulkan 使用 Vulkan 实现 Direct3D 渲染 API，但实现并不完全。

![Img](./fig/img-20250310172858.png)

遇到应用安装后，应用程序窗口黑屏的情况，可以尝试将渲染方式设置成 gdi。

![Img](./fig/img-20250212175823.png)

### 游戏应用的设置

#### 如何安装和使用proton
**Proton** 是由 Valve（Steam 的开发商）主导开发和维护的兼容层，包含了高度定制和优化的 Wine 版本、以及一系列对游戏体验优化的补丁和集成，能够让基于 Windows 的游戏和应用程序能够无缝地在 Linux 操作系统上运行。

统信Windows应用兼容引擎当前适配了两个不同的 proton 版本：

* deepin-proton：基于上游分支打包的稳定版 proton。兼容引擎在其之上添加了 wow64 支持。优点是可以在纯 64 位系统运行，可以运行绝大部分 32 位游戏，不需要安装 32 位显卡驱动。缺点是运行 32 位游戏时，wow64 会引入性能损耗，而且由于 wow64 本身的缺陷，部分 32 位游戏 deepin-proton 无法运行。
* ge-proton：可以理解为官方 Proton 的技术预览版。由社区开发者 GloriousEggroll 创建和维护的 Proton 分支版本，基于 Proton 的官方代码，但融入了更多实验性、前沿或尚未被官方 Proton 合并的补丁。由于基于二进制文件进行打包，运行部分 32 位游戏时，需要在系统安装 32 位显卡驱动才可以运行。

如何安装Proton：
在将游戏添加到兼容引擎后，需要进入到游戏应用的高级调试页面，如下图：

![Img](./fig/img-20250612185039.jpg)

在打开的调试界面里点击“安装 proton”，然后选择需要安装的 Proton 版本，点击安装后将跳转到应用商店页面进行安装：

![Img](./fig/img-20250612185615.png)

在应用商店完成安装后，回到兼容引擎，在高级调试页面 Wine 版本的下拉框里就可以选择“deepin-proton9”或者“ge-proton9”，然后重新运行应用。

![Img](./fig/img-20250612185750.png)

#### 如何安装Vulkan驱动
DXVK 是 Direct 11 的 Vulkan 实现，而 VkD3D 是 Direct 12 的 Vulkan 实现。在设置安装好 Vulkan 驱动后，就可以通过设置这两个选项来运行游戏了。

![Img](./fig/img-20250212180344.png)

A 卡用户需要安装 mesa-vulkan-drivers 。打开终端，然后输入下面的命令：
`sudo apt install mesa-vulkan-drivers`

对于 N 卡用户，需要安装 nvdia-vulkan-icd ：
`sudo apt install nvidia-vulkan-icd`

然后安装 vulkan-tools ，运行 vkcube ，能弹出 vkcube 的 demo，说明 Vulkan 显卡驱动设置完成了：
`sudo apt install vulkan-tools vkcube`

![Img](./fig/img-20250212180846.png)

关于显卡驱动安装和版本选择可以参考：[deepin 23 如何安装显卡驱动](https://www.deepin.org/zh/deepin-23-install-driver-gpu/)

### 兼容引擎运行环境修复

兼容引擎无法正常使用时，可能是系统环境出了问题，常见的情况有：

- 基础容器损坏：Wine 运行所需的 ostree 容器文件不完整或损坏
- 磁盘空间不足：系统盘空间不足，无法创建或运行应用容器

遇到这类问题，可以尝试删除损坏的容器数据后重新运行。打开终端，粘贴下面的命令并回车：

```
rm -rf ~/.local/share/deepin-wine-bottles/bottles/ostree_bottle/
```

如何打开终端：在系统桌面上空白处鼠标右键，选择"在终端中打开"即可打开终端。

删除后，在终端中运行 `deepin-wine-builder` 启动兼容引擎，然后再次尝试运行应用。如果仍然失败，请在社区发帖反馈问题，并附上终端中 `deepin-wine-builder` 的运行日志。
